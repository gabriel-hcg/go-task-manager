# go-task-manager

A task manager built in Go to practice backend fundamentals: structs,
slices and maps, error handling, JSON, packages and testing.

> **Status:** In progress. The project has just started, and this README
> describes its goals. The checklist below shows what is already done.

## Goals

- Move from syntax exercises (see my
  [go-learning-path](https://github.com/gabriel-hcg/go-learning-path))
  to a small application built from scratch
- Practice CRUD operations and data structuring in Go
- Learn to organize a Go project into packages and write tests

## Planned features

- [ ] Create a task (title, description, status)
- [ ] List tasks
- [ ] Update a task
- [ ] Mark a task as done
- [ ] Delete a task
- [ ] Persist tasks in a JSON file
- [ ] Unit tests for the core logic
- [ ] (Later) Expose the operations through a REST API using `net/http`

## Tech

- Go, using only the standard library for now
